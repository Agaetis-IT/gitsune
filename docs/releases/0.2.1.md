# Gitsune 0.2.1

A small release that fixes the side-by-side diff and makes the push and pull request dialogs clearer.

## Changes

- **Side-by-side diff.** The two sides share the width of the window again: the line numbers are narrow and the code gets the room, instead of a quarter of the width going to each column.
- **Push and force push.** The push dialog has two buttons, **Push** and **Force push**, in place of the "Overwrite the remote branch" checkbox. Force push asks for a confirmation that names the remote branch it replaces, and it still uses `--force-with-lease`, so it is refused if someone pushed since your last fetch. The dialog is wider and the "Track it" line reads on one line.
- **Pull request dialog.** **Create** makes the pull request and stays in the app; **Create and open** also opens it in the browser, as Create did before.
- **Pull request status errors.** When the pull requests of a repository cannot be read, the message names the repository (`org/project/repo`) and is shown once per repository, so you can tell which one is the problem.
