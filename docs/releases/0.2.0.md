# Gitsune 0.2.0

Stashes now show up in the graph, the app tells you when a new version is out, and several rough edges of branch menus and resets are fixed.

## Highlights

- **Stashes in the graph.** Each stash is drawn next to the commit it was made on, with its own icon. Right-click it to apply it, pop it or drop it. A stash group in the sidebar has an eye to hide them all.
- **Update check.** Gitsune looks for a newer release once a day, from _Gitsune, Check for Updates…_ or from _Settings, General, Check now_. When one is out, a window shows its notes and opens the download page. The daily check can be switched off in the settings; nothing about you or your repositories is sent.
- **Reset from a branch menu.** The menu of a local or remote branch has _Reset the current branch to…_, so you no longer need to find the commit first.
- **Hard reset of any local branch.** A branch that is not checked out can now be reset hard (its ref is moved, there are no files to rewrite). It stays refused when another working tree has the branch checked out, with the folder named in the dialog.

## Fixes

- **Delete on the remote.** Deleting a branch can now also delete it on the remote, and the remote label disappears from the graph afterwards.
- **No more console windows on Windows.** The `git` and helper commands the app runs no longer flash a console.
- **Dialog overflow.** A long file name no longer pushes the checkout dialog out of the window.
- **macOS package.** The app is signed ad hoc, which fixes the "damaged" message on Apple silicon (it still needs a right-click, _Open_ the first time).
