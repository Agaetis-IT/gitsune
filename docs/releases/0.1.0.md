# Gitsune 0.1.0

The first version of Gitsune, a desktop git client where every branch is a tail you can follow: **one colored line per branch, commits as stations, merges as interchanges**. It runs the real `git` for every change, so hooks, signing and your credentials behave as in your terminal.

## Highlights

- **A graph you can read.** Stations carry the initials of their author, lines keep their color, and it stays smooth up to about 100,000 commits. `main`, `master` and `develop` always have the same colors, and switching branches never repaints the graph.
- **Everyday git, with a safety net.** Stage files, hunks or single lines; commit and amend; branches, tags, fetch, pull, push, stash, cherry-pick, revert and reset. Most changes come with an Undo, a history of positions brings back where HEAD was, and every command the app runs is in an activity log.
- **Reset any branch to any commit.** Soft or mixed for any local branch, hard for the checked-out one. Double-click a remote label (`origin/develop`) to reset the local branch that follows it, with a confirmation.
- **Rebase and merge by hand.** Drag the commits of an interactive rebase and see the result before it runs; resolve conflicts in three panes with next and previous.
- **Pull requests without tokens.** GitHub, GitLab and Azure DevOps through the sign-in of `gh`, `glab` and `az`: build and review badges on the branches, and pull requests created from the app. From the menu of a branch, start a pull request from the current branch into the branch you clicked, or open the one that exists. The description is left empty (the host shows the commits), except for the ticket reference on Azure DevOps.
- **Remotes and tags.** Add, rename, change the address of and remove remotes from a dialog; push one tag or all of them. Remote addresses that use an SSH alias (`git@work-github:team/tool.git`) are resolved, so the hosting service is found.
- **Tabs that fit how you work.** Open, clone or pick a recent repository from a blank tab; reorder the tabs by dragging them or with `Alt` and the arrow keys; the tabs come back at the next start.
- **Made for tickets.** `AB#1234` in a branch name or a message becomes a link to the work item.
- **Fast to drive.** Command palette (`Cmd/Ctrl+K`), search, focus on an author, worktrees, blame, branches hidden or highlighted, ten themes and your own.
